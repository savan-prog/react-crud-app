# React CRUD App

A responsive CRUD (Create, Read, Update, Delete) application built with React.js, Redux, and LocalStorage. The application allows users to manage data with a clean and responsive interface.

## 🚀 Live Demo

[View Live Demo](https://savan-react-crud.netlify.app/)

## 📂 GitHub Repository

[View Source Code](https://github.com/savan-prog/react-crud-app)

## ✨ Features

* Create new records
* Display records
* Edit existing records
* Delete records
* Redux for state management
* LocalStorage for data persistence
* Responsive design
* Clean and user-friendly interface

## 🛠️ Technologies Used

* React.js
* Redux
* JavaScript (ES6+)
* HTML5
* CSS3
* Vite
* LocalStorage
* Git & GitHub

## 🔄 CRUD Operations

### Create

Add new records through the form.

### Read

Display saved records in the application.

### Update

Edit existing records and update their information.

### Delete

Remove records from the application.

## 💾 Data Persistence

The application uses **LocalStorage** to store data in the browser. This allows the data to remain available even after refreshing the page.

## 📱 Responsive Design

The application is designed to work across different screen sizes, including desktop, tablet, and mobile devices.

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/savan-prog/react-crud-app.git
```

Navigate to the project directory:

```bash
cd react-crud-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in the terminal.

## 📦 Build for Production

```bash
npm run build
```

The production build will be generated in the `dist` folder.
